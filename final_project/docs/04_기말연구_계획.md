# 4. 기말 연구 계획

> 본 절은 1~3장의 연구 목적·중간 고찰·기말 EDA를 바탕으로, **구현·실험·제출**까지의 실행 계획을 정한다.  
> 마감: **1차 2026-06-04**, **2차 2026-06-07** (`final_project_discription.md`).

## 4.1 전략 한 줄

**「BS별 학습 보정 → 강건 삼변 초기화 → (선택) 기하 잔차 게이트 → 위치 출력」**을 `train.py`에서 700명 GT로 학습하고, `main.py`는 **학습 가중치만 로드**해 1000명 규모에서 10분 이내 추론한다.

중간 V15의 **Wi-Fi 가이드**는 제거하되, **Huber·게이트·Train K-Fold·Optuna(선택)·무결 보고**는 유지한다.

## 4.2 제안 알고리즘: RTT-FusionLoc (가칭)

### 4.2.1 전체 흐름

```
[입력] d_hat (18,), p_bs (2,18)
    │
    ▼
┌─────────────────────────────────────┐
│  Stage 1: RTT 보정 (학습)            │
│  d̃ = f_θ(d̂; BS id 또는 좌표)       │
│  · 1차: BS별 (α_k, β_k) 아핀         │
│  · 2차: 작은 MLP (채널+BS embedding) │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  Stage 2: 강건 삼변 (scipy)          │
│  p₀ = argmin Σ ρ(||p-a_k|| - d̃_k)   │
│  ρ: Huber (중간 V12/V15 동일 계열)   │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  Stage 3: 기하 게이트 (선택, V15식)  │
│  |‖p₀-a_k‖ - d̃_k| > τ → k 제외      │
│  τ: Train OOF 분위 (700명, 라벨 사용)│
│  → Stage 2 재실행 → p_final         │
└─────────────────────────────────────┘
    │
    ▼
[출력] p_hat (2,)
```

**그림:** 노션에 위 블록을 다이어그램으로 옮기거나, 4.6절 일정표와 함께 배치.

### 4.2.2 Stage 1 — RTT 보정 (학습의 핵심)

3장 EDA: corr=0.815, 잔차 평균 +15.9 m → **절대 RTT를 그대로 쓰지 않는다.**

| 단계 | 모델 | 파라미터 규모 | 목적 |
|------|------|---------------|------|
| **M0 (베이스라인)** | 보정 없음 | 0 | Huber RMSE **19.3 m** (3장) |
| **M1** | BS별 아핀 \(\tilde{d}_k = \alpha_k \hat{d}_k + \beta_k\) | 36 | 체계 bias 제거 1차 |
| **M2** | M1 + 공유 2층 MLP (18→h→18) | ~수백 | 비선형 잔차 |
| **M3** | 입력에 BS 상대 좌표 \(\Delta_{k,u}\) concat | M2 확장 | 기하 힌트 |

**학습 손실 (train.py):**

\[
\mathcal{L} = \underbrace{\frac{1}{N}\sum_u \|\mathbf{p}_u - \mathrm{Trilat}(\tilde{\mathbf{d}}_u)\|^2}_{\text{위치 RMSE, fold train만}}
+ \lambda \underbrace{\frac{1}{18N}\sum_{k,u} |\tilde{d}_{k,u} - \|\mathbf{p}_u-\mathbf{a}_k\||^2}_{\text{거리 보조 (선택)}}
\]

- 위치 항은 **삼변 결과**에 대한 미분 가능 근사가 어려우면, **M1/M2로 \(\tilde{d}\)만 학습**하고 Stage 2~3는 CPU scipy로 두는 **2단계 학습**도 허용한다 (구현 단순화).
- **1차 구현(M1+Huber)** 부터 CV 곡선을 본 뒤 M2 필요 여부 판단.

### 4.2.3 Stage 2 — 강건 삼변

- `scipy.optimize.least_squares`, `loss='huber'`, `f_scale`은 Train CV로 선택 (중간 V15: 1.0~1.35).
- 초기값: BS 좌표 centroid 또는 Stage 1이 \(\mathbf{p}\)를 직접 내면 그 값.
- **Bounds:** UE 분포 x∈[-60,60], y∈[-30,30] 근처로 clip (EDA 기반).

### 4.2.4 Stage 3 — 기하 게이트 (V15 이관, RQ3)

중간 V15 HardGate가 ReWeight보다 나았던 이유(§2.7)를 RTT에 적용:

1. Stage 2로 \(\mathbf{p}_0\) 획득.
2. 각 BS \(k\): \(r_k = \big|\|\mathbf{p}_0-\mathbf{a}_k\| - \tilde{d}_k\big|\).
3. \(r_k > \tau\) 인 채널 제외 후 Stage 2 재실행.

**τ 결정 (무결):**

- 700명 Train에서 **K-Fold OOF** (V15 `train_oof_gate_row_median_stats`와 동일 취지).
- τ 탐색 구간: OOF 잔차 p12~p97, 상한 캡 (예: 3~50 m, EDA 스케일에 맞게).
- **Optuna**로 \(\tau\), `f_scale`, inflate(가중) 선택 시 **Train CV RMSE만** 최소화.

**Ablation (4.4):** Stage 3 ON/OFF — RQ3 답변용.

### 4.2.5 대안 안 B — End-to-End (후순위)

입력: \(\hat{\mathbf{d}}\) (18) + \(\mathrm{vec}(\mathbf{a}_k)\) (36) → MLP → \((x,y)\).

- **역할:** 성능 상한 탐색, `report.md`에서 “공정 비교” 논의.
- **주력 안 A가 CV에서 충분하면** B는 간략 ablation만.

## 4.3 `train.py` / `main.py` 역할 분리

과제 명세: **참신성·보고서 채점은 `train.py` + `report.md` 기준.**

| 파일 | 역할 | 수행 내용 |
|------|------|-----------|
| **`train.py`** | 학습·튜닝·모델 저장 | 700명 `p`로 M1/M2 학습, K-Fold CV, (선택) Optuna, OOF τ, `model.pt`·`calib.json` 저장 |
| **`main.py`** | 추론만 | `DH_FR1.mat` 로드 → 보정 → 삼변 → (게이트) → `(2, num_user)` 반환 |

### 4.3.1 `train.py` 상세

1. `data/InF_DH_FR1.mat` 로드, `BS_positions` 처리.
2. **K-Fold** (K=5, seed=42 고정) — fold별:
   - M1/M2 학습 (train fold만),
   - val fold에서 위치 RMSE 기록.
3. **OOF** 잔차 수집 → τ 후보 구간.
4. (선택) Optuna: Huber `f_scale`, τ, \(\lambda\) — **objective = mean CV RMSE**.
5. **전체 700명**으로 최종 가중치 재학습 → `model.pt` 저장.
6. **내부 hold-out 140명** (20%)은 **최종 1회** 평가만 (중간 V15 “검증 1회” 규약).

**산출물:**

- `model.pt` (PyTorch state_dict 또는 numpy α,β)
- `config.json` (τ, f_scale, K, seed, 버전)
- `train_cv_results.csv` (fold별 RMSE)
- `train.log` (재현용)

### 4.3.2 `main.py` 상세

```text
load DH_FR1.mat
resolve p_bs from BS_positions or p_bs
for u in range(num_user):
    d_corr = apply_calibration(d_hat[:,u], model)
    p0 = huber_trilat(d_corr, p_bs)
  p_hat[:,u] = gate_refine(p0, d_corr, p_bs, tau)  # if enabled
return p_hat
```

- **num_user 동적** — hidden 300명 시 300, 학습 mat 시 700.
- **10분 제한:** UE당 scipy 1~2회 — 1000명 × 수 ms = 여유 (중간 Turbo 3초 참고).
- 채점기에 `p` GT가 있어도 **main.py에서 사용 금지** (과제 정신상 추론만; 로컬 디버그는 별도 스크립트).

### 4.3.3 변수명 호환

로컬 `data/InF_DH_FR1.mat` vs 채점 cwd `DH_FR1.mat`:

```python
bs = data.get('p_bs', data.get('BS_positions'))
```

한 줄로 **양쪽 mat** 대응.

## 4.4 실험·평가 설계 (무결성)

### 4.4.1 공정한 baseline (report.md 필수)

| 이름 | 설명 | 공정성 |
|------|------|--------|
| **B0** | LS 삼변, 보정 없음 | 교과서 하한 |
| **B1** | Huber 삼변, 보정 없음 | EDA **19.3 m** |
| **B2** | Huber + BS 아핀 (M1), **비학습** α,β=OLS on train | 학습 vs 규칙 비교 |
| **제안** | M1(학습) + Huber + (게이트) | 본인 알고리즘 |

**금지:** 제안 모델만 딥러닝, baseline은 “교과서 삼변”만 두는 비교 (과제 §5.1 지적).

### 4.4.2 교차검증 프로토콜

| 용도 | 방법 | 라벨 사용 |
|------|------|-----------|
| 하이퍼·τ·f_scale | **5-Fold CV** on 700 | fold train만 |
| OOF 게이트 구간 | Train OOF | train만 |
| 최종 숫자 보고 (주차 보고서·report) | **hold-out 140** 1회 | hold-out 1회만 |
| Hidden 300 | **불가** | 채점기만 |

**중간 V12(검증 튜닝 1.445 m) 실수 반복 금지:** 700명에서 random split한 hold-out을 **여러 번 peek**하지 않는다.

### 4.4.3 Ablation 계획 (RQ3, 보고서 표용)

| ID | 구성 | 기대 |
|----|------|------|
| A0 | B1 (Huber only) | ~19 m |
| A1 | M1 + Huber | 잔차 bias 제거 → **대폭 하락** |
| A2 | A1 + 게이트 | V15식 추가 이득 여부 |
| A3 | M2 + Huber | A1 대비 소폭 이득? |
| A4 | E2E MLP (B안) | 해석 vs 성능 |

결과는 **markdown 표**로 `report.md`에 기입 (이미지 금지).

## 4.11 성공 지표 (정량 목표, 내부용)

Hidden 라벨 없이 **내부 hold-out 140명** 기준 목표 (실험 후 수정 가능).

| 단계 | hold-out RMSE 목표 (가이드) | 근거 |
|------|----------------------------|------|
| B1 Huber | ~19 m (확인) | 3장 EDA |
| M1 + Huber | **< 10 m** (희망) | bias 제거 |
| + 게이트 | M1 대비 **5~15% 개선** | V15에서 ~1%대 |
| 최종 제출 | **CV·hold-out 추이 일치** | 과적합 없음 |

절대 수치는 12주 CV 실험 후 `config.json`에 기록한다.

## 4.12 요약

기말 연구는 **합성 RTT 18채널**에 **학습 보정(M1→M2)** 과 **중간에서 검증된 Huber·게이트**를 결합하는 **2파일 구조(`train.py` / `main.py`)** 로 진행한다. 평가는 **B0/B1 대비 공정한 표**, **5-Fold CV 무결 튜닝**, **hold-out 1회 보고**로 중간 V12·V9의 누수를 피한다. 11주차에는 계획과 EDA까지 완료했고, 12주부터 CV 구현, 6월 4일 1차·7일 2차 제출에 맞춰 ablation과 `report.md`를 완성한다.
